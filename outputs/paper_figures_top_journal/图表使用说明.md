# 顶刊风格论文图表使用说明

## 输出规范

- 格式：PNG（无 PDF、无 SVG、无需可编辑源图）。
- 分辨率：600 dpi；白底；适合正文双栏跨栏或单栏缩放。
- 视觉规范：深蓝为主证据、橙色为关键决策/阈值、灰色为基准或边界；无渐变、无立体效果，颜色之外同时使用线型、标记或位置编码。
- 数值口径：问题二正式评估窗为 2025-02-01 至 2025-12-31（334 天）；高斯核方法暂不进入正式成本比较。

## 推荐叙事顺序

1. **先给结构**：用图0把问题一的确定性基准与问题二的不确定性闭环连接起来，并在图中直接限定“当前配置下最优”的含义。
2. **再证明输入可信**：用图7说明选择周持久性预测基线的证据，避免直接跳到成本结论。
3. **解释风险如何进入决策**：图8先展示“历史残差 → 80% 分位风险曲线”，同时交代该参数的经济含义与适用边界。
4. **解释动作如何产生**：图9把预测、风险、电价与四阶段截断仿射控制连接起来，形成可审计的机制链。
5. **最后评价结果边界**：在策略成本比较之后放图13，用完美预见下界说明剩余改进空间，并明确两种百分比口径。
6. **把算法终止问题移至附录**：附图A1用于回答“最大迭代是否失败”，正文只保留一句口径说明，避免喧宾夺主。

## 结果解读逻辑

建议统一使用下面的五层证据链：

> 数据口径一致 → 预测输入可用 → 风险修正有因果时间顺序 → 控制动作可执行 → 成本结果在理想下界与现实基准之间定位

- **第一层：口径**。所有正式比较使用相同日期范围、价格、设备参数和账单规则；配对成本差异优先于非配对绝对值。
- **第二层：预测**。MAPE 只说明预测误差，不能直接代替控制成本；因此高斯核暂不参与正式策略优劣结论。
- **第三层：风险**。风险上调只使用决策日前已有的完整残差日，避免未来信息泄漏；80% 是经济权衡参数。
- **第四层：执行**。LDR 输出必须经过功率、SOC 与账单校核；差分进化的终止标签不替代可行性验证。
- **第五层：结果**。现实策略之间用配对差额评价；与完美预见只做下界参照。当前 LDR 相比情景控制少 5,142.06 元（0.0368%），属于小幅但同口径的改进；距完美预见下界仍有 1,725,678.87 元空间。

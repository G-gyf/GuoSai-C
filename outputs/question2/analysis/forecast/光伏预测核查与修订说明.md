# 问题二光伏日前预测：核查与修订说明

2026-09-12。对照《问题二预测.docx》光伏部分对 `src/forecasting/pv_day_ahead.py` 做逐项核查，按确认口径修订并重跑。重跑前旧结果仅作对照，本文件记录核查结论、修订决定与修订后结果。

## 1. 核查结论

### 1.1 与文档一致的实现

30 日首末出力中位数（>1 kW）、硬窗口 [04:10,19:30] 与滚动边界 [r̂−60min, q̂+60min] 掩码、121 点太阳时网格 + 逐 bin 90 分位形状、SG(11,3) 滤波 + 非负 + 端点置零 + 归一化、振幅=前 30 日峰值 90 分位、双包络（P_cs^raw=A·S，P_cs^norm=A·max(S,0.02) 仅软边界内）、0.02 只防除零、KPV 与最终功率无上截断、A1-7/A1-30 分算、A2=包络×30 日 KPV 均值+90 日窗 AR(1) 残差、A3=90 日 Ridge(α=1.0)、A4=120 日 kNN（7 滞后 KPV+太阳时+sin/cos，稳健标准化，距离加权，k=5/10/20）、边界混合块识别、τ∈{0.10,0.15,0.20} 滚动选择、1 月影子预测、正式评价期 2/1–12/31、training_end < issue_ts、不使用附件 3 与外部天气，均与文档一致。

### 1.2 发现的差异及处理决定

| 编号 | 差异 | 用户决定 | 实现 |
|---|---|---|---|
| a | 附件 1 形状始终并入 90 分位形状池 | 不使用附件 1，移除 | 形状池、振幅先验、首末时刻先验全部移除；第 0 天（1/1）无历史 → 零影子预测并打 `cold_start_shadow` 标记；删除"附件 1 必须可初始化包络"检查；`build_pv_day_ahead_forecasts` 不再接收附件 1 参数 |
| b | P_cs^raw 只在 [r̂,q̂] 内置零，未按硬窗口 [04:10,19:30] 置零 | **保留代码方案** | raw 包络维持现状（仅太阳时区间内置零）；该列不进入任何候选与选择损失，仅作为产物列，差异只影响其语义。核查分析：改按文档置零对正式指标零影响，改不改均成立，按用户决定保留并在此记录 |
| c | A3 样本不足回退 `a2_base`（缺 AR 修正） | 回退完整 A2 | A3 回退值改为当块完整 A2（含 AR(1)）；A2 自身 AR 样本不足时自然退化为 a2_base |
| d | A4 样本不足回退未文档化 | 规定回退链 | 见下节 |
| e | 选择器含集成、1% 门槛、滞回 | 改为严格胜者切换 | 见下节 |

### 1.3 规定的回退链（d）

```
A4（k=5/10/20 逐块）→ 完整 A2（含 AR）→ a2_base（A2 的 AR 样本不足）→ 0（非有效日照小时置零）
A3（ridge 逐块）    → 完整 A2（含 AR）→ a2_base → 0
```

回退按小时块计数并写入产物：`hourly.a3_a2_fallback_hours`、`hourly.a4_a2_fallback_hours_k{5,10,20}`，汇总见 `forecast_summary.json`。逐月分布显示回退集中在夜间/边界小时（KPV 无定义）与 1 月预热期，属预期行为；正式期白天核心小时几乎不发生回退。

## 2. 选择机制修订：严格胜者切换

- 规则：滚动 30 日损失；有效历史日 <14 → 默认 a1_7。候选池 = {a1_7} ∪ {a2,a3,a4_k5,a4_k10,a4_k20 中滚动损失严格低于 a1_7（容差 1e-12）者}；赢家 = 池中滚动损失最低者；平手回 a1_7。
- 取消：逆损失加权集成、1% 改善门槛、前一策略滞回；a1_30 只作对照指标，不参与切换。
- `ensemble` 不再出现在任何选中结果中；hourly 表中 `ensemble_loss` 列保留但恒为 NaN（schema 兼容）。

## 一、问题界定（写进论文的一段话）

问题四在波动电价下重算问题三，其最后一小问对应问题三“请分析是否需要引入其他时刻的预报
制定调整购电策略”。在波动电价下，“其他时刻的预报”包含两个可分离的新信息成分：

1. **新增光伏预报**：在官方 0:00/6:00/12:00/18:00 发布之外，于候选整数时点用
   “最新官方发布＋当日动态残差修正”自建光伏预报（与问题三第二小问预测层同构，数据相同）；
2. **新增电价更新预报**：在候选时点利用当日已揭示的区间电价（区间起点 ≤ 候选时刻），
   对日前周持久化电价预报做日级乘性水平修正（42 日滚动 OLS 收缩、乘子截断于 [0.5,1.5]），
   严格因果。

对每个候选时点从同一条 M612 路径、同一真实 SOC 分叉六组成组策略
（B 基准 / S 状态重优化 / Fpv 光伏预报 / Fp 电价更新 / Fboth 两者 / O 完美信息上界），
全年连续运行、期末库存只计价一次，把“状态重优化价值”与“新增预报的纯增量价值”分开。

## 二、求解可行性结论（先回答“确保求解可行”）

1. **构造可行**：候选时点调整 LP 恒存在平凡可行解（c=d=0、a=max(R−V,0)、u=max(V−R,0)、
   储能不动），因此任何候选时点、任何信息分支的调整问题按构造必然可行；执行层由紧急购电
   兜底，亦恒可行。新增预报时刻不会引入不可行风险。
2. **数值审计**：全部 54 个全年回测中，候选时点调整 LP 共求解 **17,368 次、全部最优**，
   失败 0 次、触发“沿用已锁定计划”保底 0 次；所有分支物理校验通过（最大能量平衡误差
   4.5×10⁻¹³ kWh、SOC 递推误差 0、无同时充放电、无紧急购电同时充电、已执行区间不被改写）。
3. **因果性**：电价更新只用候选时点及以前已开始区间的实际价，光伏自建预报只用候选时点及
   以前的观测，均经篡改测试验证（篡改未来数据不改变当日决策）。
4. **回归一致性**：扩展实现中的 B 分支与已锁定 Q4-3 v2 M612 主结果逐日对照 334 天，
   总费差、单日最大费差、SOC 差均为 **0.000000**——新增预报机制没有改变主策略路径。

## 五、结论（论文直接可写）

1. **需要新增预报，且新增的是光伏预报时刻。** 10:00 与 14:00 的自建光伏预报分别带来
   库存调整后纯预报价值约 **10.9 千元 / 11.3 千元**，5/5 种子为正、95% 块自助 CI 下界
   大于 0、9/11 月份为正、超过主方案年费 0.05% 的实质门槛、上界捕获率 19%–34%，
   且紧急购电费与电量均不恶化。两时点同时引入仍有独立增量
   （V10|14 ≈ 12.3 千元、V14|10 ≈ 10.4 千元），组合方案 10F+14F 库存调整成本
   **14,572,679.03 元**，相对 M612（14,638,567.99 元）全年合计节省约 **6.6 万元**
   （含状态重优化价值）。
2. **日内电价更新预报在预测层有效，但经济价值≈0。** 单独引入时价值为 −17 元（10:00）
   与 −591 元（14:00，CI 显著为负）；在光伏预报之上叠加电价更新的边际价值为
   +31 元（10:00）/−620 元（14:00），均不显著。原因是：上午 10:00 的决策窗口仅 2 小时且
   12:00 官方更新随即覆盖，下午窗口的风险主要由负荷/光伏主导、电价水平修正不改变
   价格加权分位数下的购电结构。**结论：为“调整购电策略”而单独新增电价更新预报没有必要；
   电价更新可作为光伏预报的伴随信息发布，但论文不把节费归因于它。**
3. **求解可行。** 新增预报时刻不改变调整 LP 的构造可行性（平凡可行解存在），全年 17,368 次
   候选 LP 全部最优、0 失败、0 保底，全部物理与因果校验通过，B≡M612 逐位一致。
4. **相邻时点稳健性。** 9:00（V_both 11.2 千元、捕获率 19.0%）经济价值与 10:00 相当，但
   其预测层改善（RMSE 11.2%/MAE 14.0%）显著低于 10:00（20.9%/21.5%），维持 10:00 为
   主候选；11:00（6.2 千元，低于门槛）、13:00（9.0 千元）、15:00（8.1 千元）均不改变结论。
   15:00 的状态重优化价值很高（V_state ≈ 55.2 千元），说明下午“仅凭当前 SOC 重解”
   就有可观收益，但这属于状态价值而非新增预报价值，与本小问结论口径一致。
5. **与问题三第二小问的衔接。** 固定电价下 10:00 已进入主策略（纯预报价值 10,067 元）、
   14:00 因 CI 下界不严格为正暂缓；波动电价下 10:00 与 14:00 均通过全部门槛，且价值
   量级与固定电价下一致（约 1.1 万元/年），说明“新增光伏预报时刻”的结论对电价波动稳健。

**主策略升级建议**：M612 + 10:00 + 14:00（仅新增光伏自建预报，不单独新增电价更新预报）。
正式期总费口径维持已锁定的 result4-3.xlsx（M612）不变；本小问结果用于论文分析章节。

# 差分进化终止证据说明（2026-09-13 修订）

## 1. 保存方式

每日参数表（`question3_daily_parameters.csv`）对每次校准直接落盘：`cal_i_nit`（实际迭代代数）、`cal_i_success`、`cal_i_termination`（`maxiter_budget` / `population_collapse_convergence` / `warmup_zero_parameter`）与 `cal_i_evaluations`（nfev + 2 个保底评分）。首版运行仅保存 nfev 与通用消息、不区分终止方式，其统计曾由 nfev 精确重建（见旧版说明）；本版起直接落盘，统计见 `DE_termination_stats.csv`。

## 2. 终止机制

tol=0、atol=0 时 scipy 差分进化的收敛判据退化为"种群能量标准差为 0"，即全部候选目标值**精确相等**才早停。保留阈值经 clip 截断形成目标函数平台，种群常在数代内塌缩到同分（记作 population_collapse_convergence）；否则运行至 maxiter=8 代（maxiter_budget）。固定配置：strategy=best1bin、popsize=5、maxiter=8、updating=deferred、init=latinhypercube、mutation=(0.5,1.0)、recombination=0.7、polish=False、种子=20250912+10d+序号。

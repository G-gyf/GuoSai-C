# 差分进化终止证据说明（2026-09-13）

## 1. 现状与原因

首版全年运行的每日参数表（`question3_daily_parameters.csv`）只保存了每次校准的 `evaluations`（nfev+2 个保底评分）与求解器通用消息 `solver_message`（"Optimization terminated successfully."），**未保存 `result.nit`（实际迭代代数）、`result.success` 与终止方式标志**——原因是最初的 `calibrate_staged` 只提取了 message 与 nfev 两个字段，而该 message 不区分"达到 maxiter 预算"与"满足收敛条件"两种终止方式。

代码已修补：`calibrate_staged` 与每日诊断提取现记录 `nit / success / termination`（`maxiter_budget` 或 `population_collapse_convergence`），下一次全年运行起直接落盘。本次运行的结果无需重跑：终止方式可从已保存的 `evaluations` **精确重建**，因为差分进化固定配置（tol=0、atol=0、maxiter=8、popsize=5、updating=deferred），达到预算时的 nfev 恒为 `(maxiter+1)×popsize×N`（N 为维度，加 2 个保底评分即保存值），不足该值即为早停日。

## 2. 终止机制

tol=0、atol=0 时 scipy 差分进化的收敛判据退化为"种群能量标准差为 0"，即全部候选的目标值**精确相等**才早停。由于保留阈值经 clip 截断，参数空间中大片区域的候选产生完全相同动作与分数（目标函数平台），种群常在数代内塌缩到同分。达到预算（8 代）的判据为保存评价数等于 `2+9×5×N`。

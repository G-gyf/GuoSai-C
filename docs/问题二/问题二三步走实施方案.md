## 1. 共享数据 / 情景 / 信息状态层（三步共用，不改口径）

- **预测**：`L̂_t = mean(L_{d-7..d-1, t})`，`V̂_t` 同理；`N̂_t = L̂_t − V̂_t`。
- **残差**：`ε^L = L − L̂`、`ε^V = V − V̂`，取最近 21 个有效完整日，负载/光伏**同日配对**。
- **情景**：`N_{t,ω} = [L̂_t + ε^L_ω]^+ − [V̂_t + ε^V_ω]^+`，`ω=1..21`，`p_ω = 1/21`。整条日曲线配对以保留日内自相关（沿用现状口径）。
- **信息统计量（新增，步①②共用）**：
  \[
  a_{t} = \frac{1}{t}\sum_{s=1}^{t}\bigl(N_{s}^{\mathrm{obs}} - \widehat N_s\bigr),\qquad t=1,\dots,144
  \]
  `a_t` 是“截至当前时段的累计净负荷预测误差均值”，是日内唯一允许进入决策的已观测信息摘要；它同时充当 LDR 的输入变量与 SDDP 的增强状态。

- **（可选 DRO）**：21 条样本对分布估计噪声较大，可在经验分布周围建 Wasserstein 模糊集，把“最坏分布”纳入目标，得到分布鲁棒解。作为第二步探索，不进入第一版主线。

## 2. 步③：CVaR 风险厌恶日前规划（升级主方案的 80% 分位数）

### 2.1 模型

决策变量：`g_t`（共同计划，跨情景同一）、追索变量 `C_{t,ω}, D_{t,ω}, b_{t,ω}, U_{t,ω}, E_{t,ω}`，以及 CVaR 辅助变量 `ξ, w_ω`。

目标：
\[
\min_{g,\xi,w}
\left[
\sum_t c_t g_t
+ \frac{1}{21}\sum_{\omega}\sum_t 5 c_t b_{t,\omega}
+ \rho\,\mathrm{CVaR}_{\alpha}\Bigl(\textstyle\sum_t 5 c_t b_{t,\omega}\Bigr)
\right]
\]

CVaR 线性化（纯 LP，无二进制）：
\[
\mathrm{CVaR}_{\alpha}(Z_\omega)=\min_{\xi}\Bigl\{\xi+\frac{1}{(1-\alpha)\,21}\sum_\omega w_\omega\Bigr\},
\quad
w_\omega \ge Z_\omega - \xi,\quad w_\omega \ge 0.
\]

### 2.2 约束

每个情景满足（沿用现状 LP）：
\[
g_t + b_{t,\omega} + V_{t,\omega} + D_{t,\omega} = L_{t,\omega} + C_{t,\omega} + U_{t,\omega},
\]
\[
E_{t,\omega} = E_{t-1,\omega} + \eta C_{t,\omega} - D_{t,\omega}/\eta,
\]
\[
1200 \le E \le 10800,\qquad 0 \le C,D \le S=833.33,\qquad g,b,U \ge 0.
\]

### 2.3 关键点

- **追索变量不得自由选**：必须由步②的日内规则（或步①的价值函数）绑定，否则又回到乐观性。
- **参数含义**：`ρ=0` 退化为期望成本；`α` 是置信水平（建议 0.90/0.95 敏感性）；`ρ` 是风险厌恶权重。二者属于另一路风险设计；当前正式主线已固定α=0.8，不以此替代。
- **产出**：`g`（回填计划购电量）+ 紧急费尾部风险定量报告。
- **参数只允许用截至决策日的历史选**，不得用全年结果回写。

## 3. 步②：仿射决策规则（LDR）——保证“日前评估 = 日内执行”

### 3.1 保留阈值做成仿射规则（替代 `β·(Ep−Emin)` 与三分位分组）

控制阶段 `k=1..4`（0–6、6–12、12–18、18–24），阶段开始时用已观测误差均值 `a_{k,ω}`：

\[
R_{k,\omega} = R_{k}^0 + \lambda_k \cdot a_{k,\omega},
\qquad
R_{1,\omega}=R_1^0\quad(\forall\omega).
\]

- 待定系数仅 `4 个 R^0 + 3 个 λ = 7 个`；`R` 只依赖已观测信息 `a` + 日前定死的系数 → **非预见性由构造保证**。
- 相对现状：更少参数、更多自由度、无三分位噪声；相对“10 个常数阈值”更平滑。

### 3.2 日前把充放电绑定为等式规则

记 `r_{t,ω} = N_{t,ω} − g_t`：

\[
C_{t,\omega}=\min\Bigl\{(-r_{t,\omega})^+,\ S,\ \tfrac{E_{\max}-E_{t-1,\omega}}{\eta}\Bigr\},
\]
\[
D_{t,\omega}=\min\Bigl\{r_{t,\omega}^+,\ S,\ \eta\,(E_{t-1,\omega}-R_{k(t),n_{k(t),\omega}})^+\Bigr\},
\]
\[
b_{t,\omega}=r_{t,\omega}^+-D_{t,\omega},\qquad
U_{t,\omega}=(-r_{t,\omega})^+-C_{t,\omega}.
\]

这套等式**直接保证**：富余才充、缺口才放、不同时充放电、不为充电紧急购电、满足功率与库存边界（已逐项核验）。

### 3.3 精确 MILP 等价

`min(·)` 与 `(·)^+` 用 big-M / 指示约束精确化（不能只写上界，否则动作又获得额外自由）：
- `y = min(a1,a2,a3)`：`y ≤ a_j`，`y ≥ a_j − M_j(1−z_j)`，`Σz_j = 1`，`z_j ∈ {0,1}`；
- `(·)^+` 用二元变量拆分正负部；
- big-M 用有效界：`S`、`E_max−E_min`、`max|N−g|`。

规模约 **1.5 万二进制/天**，需装 `highspy`（HiGHS 的 MIP 接口；当前环境 `scipy.linprog` 不支持整数）。

### 3.4 日内执行（一致性）

用观测值算 `a_k`、`r_t`，代入**同一公式**计算 `C,D,b,U`，更新真实库存，跨日继承。**日前评估与日内执行严格一致**，`result2.xlsx` 可直接回填。

> 若想规避 MILP，可用**纯仿射 LDR**（`x_{t,ω} = x^0_t + Σ_{s≤t} β_{t,s} ε_{s,ω}`）保持全 LP，但可解释性下降、需额外可行性约束；第一版主线仍用阈值规则 MILP。

## 4. 步①：SDDP / ADP 价值函数（升级情景法价值函数）

### 4.1 修什么

情景法现在的价值函数是 `H̄_t(e) = mean_ω H_{t,ω}(e)`，其中 `H_{t,ω}` 是**每条情景完全知道未来**时算的，即 `E[min cost]`，天然乐观。SDDP 把它换成**同一因果策略下的期望价值函数** `V_t(e,a)`（`min_policy E[cost]`），严格非预见。

### 4.2 增强状态与 Bellman 递推

状态：`(e, a)`——SOC + 信息统计量。仅 `e` 不足以承载日内强自相关，加入 `a` 后相关性由状态表达。

动作 `x`（内部库存增量），`ψ(x) = x/η (x≥0)、ηx (x<0)`，动作集：
\[
A(e,r)=\begin{cases}
[-\min(S/\eta,\,e-E_{\min},\,r/\eta),\,0], & r>0\\[2pt]
[0,\,\min(\eta S,\,E_{\max}-e,\,\eta(-r))], & r<0\\[2pt]
\{0\}, & r=0
\end{cases}
\]

Bellman（非预见）：
\[
V_t(e,a)=\mathbb E_{\omega}\Bigl[
\min_{x\in A(e,\,r_{t,\omega})}
\Bigl\{5c_t\bigl(r_{t,\omega}+\psi(x)\bigr)^+ + V_{t+1}\bigl(e+x,\ \tfrac{t a+(N_{t,\omega}-\widehat N_t)}{t+1}\bigr)\Bigr\}
\Bigr]
\]
终端：`V_{T+1}(e,a) = −ν e`（首版 `ν=min(c)/0.9`，升级为**次日 look-ahead LP 对偶**）。

### 4.3 关键区别与优势

- `x` 在可行区间内**任意选**，由价值函数决定“当前缺口要不要放电、富余要不要充电”，不再被“必放到阈值 R”限制 → 能表达“缺口出现但未来更贵，保留库存、紧急顶过”的智能动作。
- 价值函数用 **Benders 割**逼近 `V_t(e,a) ≥ α + β_e e + β_a a`，对 `(e,a)` 线性，**无需网格离散**（对比现状 25 kWh 网格）。
- **样本路径**：21 条配对残差日整条贯穿全天抽样，日内相关性自动保留；向后回代加割、向前采样生成轨迹，迭代收敛。

### 4.4 `g` 与 SDDP 的关系（两阶段）

1. 日前用步③的 CVaR-SP 定 `g`（`g` 全天锁定、跨情景同一、非预见）；
2. 日内用 SDDP 价值函数（给定 `g`）逐时段执行。

### 4.5 全 LP 优势

SDDP 割、CVaR 线性化、日前 SP 全部是 LP/凸优化，**步①③可不依赖 MILP 求解器**（scipy 即可），是它相对步②阈值规则在工程上的一大优点。

## 6. 工程路线

### 6.1 依赖

- 主线 C：`pip install highspy`（HiGHS MIP）。
- 强化 D、步③：现有 `numpy/pandas/scipy` 即可。

### 6.2 pilot（先四日，出对照数字再定全年）

- 日期：3/20、6/21、9/23、12/21 + 前后若干日。
- 固定 `g`、同初始库存，对比三执行器：SDDP 价值函数 / LDR 阈值 / 现状贪婪阈值（`execute_slot`）。
- 输出：单日费用、紧急购电量、求解耗时、价值函数割收敛、`(e,a)` 网格/割误差。

### 6.3 全年回测

- 1 月预热（6000 kWh 起步）、2—12 月正式（334 天）；跨日库存连续。
- 独立因果账本；`ρ, α, λ, R^0, ν` 只用截至昨日历史选，不反向调参。

### 6.4 校验（沿用具现有验收）

- 物理：逐时供需平衡、SOC 递推与跨日连续、功率/库存边界、无同时充放电、无紧急购电充电。
- **非预见性“未来扰动不变性”检验**：固定某时刻前全部输入，改动之后数据，验证之前动作完全不变。
- 费用独立复算；官方模板回填后复读每个购电值、每个充放电块、每条紧急区间。

### 6.5 回填与产出

- `result2.xlsx` 沿用官方模板映射（末列“0:00-0:10+1”= 次日 00:00—00:10，本行前 143 列=当天 00:10—24:00，12-31 末列填 0）。
- 新增 `outputs/question2_sddp/`、`../../outputs/question2/current/ldr/`（不覆盖现有结果）。

## 8. 论文表述要点

- 主线 C：**“基于有限信息状态与仿射决策规则的 CVaR 风险厌恶两阶段随机规划”**，声明“在所选决策规则族内优化”。

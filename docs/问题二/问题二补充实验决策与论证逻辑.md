## 1. ③ 覆盖率审计（已用现有账本直接算出）

对正式期 48,096 个区间，审计"实际净负荷 ≤ 80% 分位数风险曲线"：

| 指标 | 数值 |
|---|---|
| 整体覆盖率 | **76.94%**（名义 80%） |
| 条件覆盖率（仅 N̂>0 时段，n=38,138） | 77.45% |
| 越过风险曲线的区间数 | 11,089 |
| 越过区间的平均超额 | 36.97 kWh |
| 越过区间中发生紧急购电的比例 | 13.36% |
| **紧急购电区间中 N_obs>Ñ 的比例** | **95.24%** |
| 分月覆盖率 | 75.09%（5/7 月最低）～ 79.61%（2 月最高） |
| 分日类型覆盖率 | 节假日 73.68%（10 天）< 周日 76.92% ≈ 工作日 77.05% ≈ 周六类 77.10% |

**解读（可写入"模型检验/讨论"）**：
1. 经验分位数系统性偏乐观约 3 个百分点，与负载预测模块此前对 q90 名义上界审计（名义 90% 实际 87.2%）是同一现象：21 天滚动窗的逐时段经验分位在样本少、非平稳（季节漂移跨窗）与 [·]⁺ 截断下，对尾部估计偏乐观。
2. **紧急购电的直接诱因几乎全是风险曲线覆盖失败**（95.24%），但越过风险曲线大多被储能放电吸收（仅 13.36% 演变为紧急购电）——这定量验证了"分位数计划＋储能追索"两层结构的分工，是很有解释力的新证据。
3. 分月/分日型覆盖有结构但不算极端（73.7%~79.6%），固定 α 在月份间略有失配。

**校准方案（可选对比臂）**：按滚动因果口径（只用 d 之前数据）估计"使实际覆盖率回到 80%"的逐月/逐日类型名义分位水平 α_bucket，作为"覆盖率校准分位数"策略臂，独立全年回测后与 LDR 并列报告。框架上这不是调参获胜——报童推导要求 P(N≤g)=0.8 相对<strong>真实分布</strong>成立，校准只是让经验分位数实际兑现名义水平；但若该臂费用低于 LDR，仍需按"主方案变更"程序处理（改写口径文档、重出 result2.xlsx），不能静默替换。

## 2. ② δ-only vs δ+λ（必补）

- **要证什么**：反馈项 λ（对已观测误差的自适应响应）在截距 δ 之外确有增益——论文 §11 局限第 6 条自认"没有单独移除仿射斜率的对照"。
- **协议**：θ 中 3 个 λ 的边界锁定 (0,0)（或直接退化为 4 维 δ 搜索），其余配置不变（35 个体×8 代、零参数保底、种子 20250912+d）；跑①独立全年账单、②在 LDR 同计划同日初库存下的配对回放。
- **实测结果**：δ-only 独立全年 13,974,466.27 元，比完整 LDR 低 3,610.97 元（−0.026%）；配对回放差 −3,708.85 元；样本内经验目标改善 210,505.77 vs 211,878.18 元（λ 仅 +0.6%）。**λ 无样本外增益，差异小于种子噪声带（6,923 元）；增益全部来自阶段截距 δ**。两种口径逐日紧急购电完全一致（结构收敛性，已核验非缺陷）。
- **论文落点**：关闭 §11 第 6 条局限，改写为结论；控制器消融小节（紧接 β=1/β=0 与配对回放）。

## 3. ④ 共同期初 SOC 公平回测（应补）

- **要证什么**：T1 四策略对照中，情景价值控制的 2/1 期初 SOC（1,738.00 kWh）低于其余三方案（LDR/β=0 同为 2,263.21，β=1 为 2,306.45），评委最可能质疑"期初库存差异混淆了策略排序"。共同起点回测直接排除该混杂。
- **关键事实**：LDR 与 β=0 的 2/1 SOC 本来就相同，因此只需重跑 β=1 与情景价值控制两个方案；预测/残差输入与 SOC 无关（只用 d−1 及以前实际数据），可直接从 2/1 以 2,263.206580 kWh 起跑。
- **协议**：共同 SOC 取 LDR 自然值 2,263.206580 kWh（主方案自身 1/31 期末，是最自然的共同起点）；跑 2/1–12/31，报 T1′（共同起点账单＋年末 SOC）与 T1（自然账单）并列。
- **实测结果**：排序不变——LDR 13,978,077.23 < 情景 13,982,967.84（−251.45）< β=0 14,042,836.06（0）< β=1 14,165,207.63（+20.67）；LDR 对情景方案优势 5,142.06→4,890.61 元；β=1 起跑 SOC 低 43.24 kWh 仅改变账单 +20.67 元，三套分位数方案年末 SOC 全部收敛 1,627.33 kWh（轨迹吸引子）。**排序对期初 SOC 口径稳健**。
- **论文落点**：T1 之后紧接"公平性对照"一小节，与已有的匹配完美信息下界（同样按各策略期初库存匹配）呼应。

## 4. ① 残差窗口 × 随机种子（建议补）

- **要证什么**：主结果对两个未定超参（21 天残差窗、DE 种子）不敏感；至少证明<strong>排序稳定</strong>（LDR 在各格子均低于 β 基线），而不只是数值不变。
- **协议**：M∈{14,21,28} × 种子 base∈{20250912, 20250913, 20250914}。注意：种子只影响 θ（g^Q 由 LP 唯一确定），窗口同时影响风险曲线与情景池。每个 M 另跑 β=1/β=0 各一次（它们无 DE、不依赖种子）。合计 3×2＋3×3＝15 次全年运行，约 15 分钟。
- **报告**：3×3 正式期总费表＋相对主配置（M=21, base=20250912）的最大偏差＋每个格子"LDR vs β 基线"的胜负。
- **实测结果**：9 格全部 LDR < β=0 < β=1（排序稳定，无翻转）；同窗口种子极差 M=14/21/28 分别为 3,209.62/6,923.26/577.91 元（≤0.05%）；9 格总极差 79,488.35 元（0.5687%）由 M=14 驱动（其 LDR 比主配置低约 0.53%）。种子影响可忽略，窗口影响绝对水平但不影响排序；主配置保持 M=21。
- **纪律**：网格结果**不得**用于回选主配置——主结果保持 M=21、种子 20250912+d（这与"80% 分位固定不扫描"是同一条纪律）。

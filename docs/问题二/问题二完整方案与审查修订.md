# 问题二完整方案与审查修订

2026-09-12更新。用户固定α=0.8，不以全年扫描重新选参；负载预测口径统一为周持久化 L_{d-7}（d<7 使用昨日持久化 L_{d-1}，仅预热期），光伏预测为七天均值。本文记录模型演进与审查；完整论文正文及最终口径见[问题二完整解答](../../outputs/question2/current/paper/问题二完整解答_LDR主方案.md)。LDR在当前数据口径、参数边界、搜索预算和已完成对照范围内费用最低，现确立为主方案。LDR升级已按本文完成独立全年验证，结果位于`../../outputs/question2/current/ldr/`；旧方案账单仍保留原名称，旧方案文档仅作历史记录。

## 1. 目标、信息与物理口径

每天0:00锁定144个10分钟时段的普通购电量，全天不调整；日内储能响应当前净负荷，余下缺口按当前电价5倍紧急购电。普通购电全额付费，未使用不退，无售电。0:00 计划只覆盖当日 00:00—24:00 的 144 个区间，不包含次日 00:00+ 的任何购电；结果模板末列“0:00-0:10+1”仅为展示映射（当日首区间购电量），12/31 末列填 0。

只使用附件1固定电价、附件2历史负载与光伏。kW除以6转换为kWh；电价与供需时刻沿用已确定的项目映射。充放电量C、D为交流侧电量，E为内部库存；η=0.9，Emin=1200、Emax=10800 kWh，S=5000/6 kWh。不加硬爬坡或题面未规定的紧急购电上限。未利用供能U可能混合光伏和计划电，不能全部称为弃光。

日初库存继承前日实际期末，不强制每日首末相等。当前区间供需按实时响应假设揭示；任何日内动作均不得读取未来实际数据。计划与规则参数只用前一天及更早的数据确定。

## 2. 负载周持久化与光伏七天预测、21天历史误差

Lhat[d,t]=L[d-7,t]（负载周持久化；1≤d<7 退化为昨日持久化 L[d-1,t]，仅预热期），Vhat[d,t]=mean(V[d-7:d,t])（光伏七天均值，历史不足时用已有天数），Nhat=Lhat−Vhat。

历史误差epsL、epsV必须由历史日当时已有的预测计算（负载为七天前同日曲线、光伏为当时七天均值）。取最近21个有效完整历史日，同一天负载和光伏误差配对：

N[d,t,w]=max(0,Lhat[d,t]+epsL[w,t])−max(0,Vhat[d,t]+epsV[w,t])。

完整日曲线作为一个情景，权重1/M，保持样本内日内联系；当天实际数据不得进入残差池。21条样本不能视为真实总体分布已知。

## 3. 固定80%分位数的日前购电LP

Ntilde[t]=max(Nhat[t],Q0.8(N[t,1:M]))；继续使用现有线性插值分位数。

依据：无储能、单时段、无剩余价值时，min_g{c g+5c E[(N−g)+]}的解为非负可行域上的80%分位数；连续分布由c−5c P(N>g)=0得到。离散分布用分位数/次梯度条件描述，线性插值并非对每个有限样本都恰为经验目标唯一最优点。

因此0.8作为由五倍紧急价支持、预先固定的风险设计。不能把简化模型最优性推广到包含储能耦合、max保护项、日末价值的完整模型，也不能解释为全天80%供电可靠性。历史alpha扫描仅作探索记录，不用于选参。

日前LP：

min Σc[t]g[t]−ν Ep[T]，ν=min(c)/η；

g[t]+Dp[t]=Ntilde[t]+Cp[t]+Up[t]；

Ep[t]=Ep[t−1]+η Cp[t]−Dp[t]/η；

Emin≤Ep≤Emax，0≤Cp,Dp≤S，g,Up≥0，Ep[0]=实际E0。

先最小化代理目标，再在10^-6元容差内最小化吞吐量，并核验充放电互斥。输出固定计划g^Q和参考库存Ep。Ep不是实际执行库存。

## 4. 推荐LDR升级：固定g^Q，日前校准同一因果规则

保留分位数LP生成的g^Q，不在第二层重新自由优化g。这样80%分位数仍明确决定购电计划。

划分0–6、6–12、12–18、18–24时四阶段。在每个阶段开始时，仅用此前已完成区间计算净负荷预测误差均值a_k；第一阶段a_1=0，阶段内固定该统计量。日前模拟情景时也严格按此口径。

保留阈值：R[t]=clip(Ep[t]+δ[k(t)]+λ[k(t)]a[k(t)],Emin,Emax)。

待定参数为4个δ和后三阶段3个λ，λ1固定0。δ=λ=0精确包含原β=1阈值；所有δ=−9600、λ=0经过截断精确包含β=0阈值Emin；这是“截断仿射保留阈值＋分段充放电规则”，不能称全部动作都是纯线性LDR。

首版可预设δ∈[−9600,9600] kWh、λ∈[−2,2]，作为待验证工程范围，不以全年结果反向挑选范围。截断保证真实误差超出历史范围时阈值也合法。

记r=N−g^Q，e为上一时段库存，统一执行函数为：

C=min(max(−r,0),S,(Emax−e)/η)；

D=min(max(r,0),S,η max(e−R,0))；

b=max(r,0)−D，U=max(−r,0)−C；

E_next=e+η C−D/η。

R∈[Emin,Emax]保证库存与功率可行，富余才充、缺口才放、无同时充放电、不用紧急购电充电。相同信息、库存、g与参数必然产生相同动作，不要求不同历史情景的动作无条件相同。

0:00在M条历史情景上从相同实际E0递推此函数，选择θ=(δ,λ)：

min_θ J_d(θ|g^Q)=Σc g^Q+(1/M)Σ_w[Σ_t5c[t]b[t,w;θ]−ν E[T,w;θ]]。

固定g时计划费是常数，但保留用于完整费用展示。当天参数与g均锁定；日内仅输入实际已知观测、真实库存，原样调用执行函数。

## 5. “日前日内统一”的准确含义

同一输入路径、g、参数和初始库存下，日前情景推演与日内执行逐时一致；不要求预测情景与真实路径的费用、动作相等。

当前固定阈值已经因果，LDR不是因果性的必要条件。即使零阶固定规则也能通过同函数实现一致评价；增加仿射项是扩展策略适应能力，不保证降低样本外费用。

本方案是分层近似方法：第一层用0.8风险LP生成计划，第二层用统一规则评价情景并优化参数。它修复第二层的评价—执行差异，但第一层仍是代理规划，不能声称完整日前LP等于真实期望费用最优化。

如果要使g也在统一规则下联合优化，就必须换成规则约束情景模型，重新明确0.8在哪个约束或风险指标中发挥作用。仅把原LP的输出命名为LDR无法做到这一点；当前推荐不采用这个扩展。

## 6. 求解与成为主方案的条件

首版优先共用执行函数，对7个规则参数做预算有限的直接情景搜索；当前实现显式保留β=1对应的零参数候选；β=0可由规则族表达，但未显式加入保底候选，记录方法、种子、评价次数和耗时，只接受经验目标不劣于零参数基线的结果。不宣称全局最优，也不把经验目标改善等同于真实账单改善。当前337个完整残差窗日期中，324天达到最大迭代预算，13天满足算法终止条件；达到预算后被接受仅表示候选满足可行性和零参数保底检查，不表示搜索全局收敛。

若使用MILP，应精确表达全部min、正部和截断，给出有效变量界和big-M；仅有上界不等价。求解后用执行函数逐情景回放核对，并披露gap及超时情况。此前未通过审查的`question2_ldr.py`已重写为固定购电计划下的预算有限直接搜索，不再使用原联合优化MILP。当前实现让情景评分与日内执行共用同一状态转移函数，并以固定种子、评价次数和逐日诊断记录搜索过程。

验收顺序：

1. 所有时段平衡、库存递推、跨日连续、功率边界、充放电互斥、无紧急购电充电；原电价独立复算账单。
2. 情景评价与日内执行同函数逐时一致；θ=0回归原β=1。
3. 扰动未来实际数据不改变此前计划、参数和动作；优化种子等不能包含未来信息。
4. 固定同g、同日初库存比较β=1、β=0、LDR，隔离控制效果；另各自从1月2日6000 kWh独立连续运行全年（1月1日为冻结初始条件日：无计划、电池不动作、SOC 恒 6000 kWh、不入统计），评价整套策略。逐日重置库存对照不能冒充全年策略。
5. 规则参数按当日前历史确定，不用全年真实结果回写。比较实际总费、紧急费/电量、未利用供能、期初期末库存、计算时间。
6. 正确性通过后还需审查费用表现；仅加入LDR或通过可行性测试不足以自动替代主方案。升级无费用优势时如实披露并保留原方案，不以复杂度替代经济性证据。

## 8. 已有证据与撤回项

正式期现有β=1方案14,165,186.96元，风险β=0对照14,042,836.06元，情景价值控制13,983,219.29元（负载周持久化，统一口径后的当前对照方案）。LDR主方案为13,978,077.23元，分别低于前三者187,109.73元、64,758.83元和5,142.06元。LDR通过物理、因果信息、参数边界、费用复算与官方工作簿回读校验；同计划、同日初库存的配对回放也显示LDR累计费用低于β=1和β=0。以上真实账单排序、配对控制器证据和可行性校验共同支持“当前配置下最优”的表述。该结论只适用于当前数据口径、参数边界、搜索预算与已实现策略集合；相似日高斯核暂不接入本轮费用回测，不纳入该候选集合。情景价值控制仍保留为对照。

撤回：当前方案已达信息可达前沿、剩余差额是不可约预测误差、控制器因果性免费、CVaR/DRO必然无收益、0.8是完整储能问题全局最优参数、SDDP必然严格优于已有方法等结论。

差额仅在匹配时间域、初始库存、计划和动作约束后解释。固定计划的完美未来调度是事后反事实，不是可执行策略，也不能识别纯预测误差或纯因果性代价。当前LDR主方案与同起始库存匹配完美信息下界12,252,398.36元相差1,725,678.87元；该差额占LDR实际费用的12.35%，若以下界为基准，则LDR实际费用比下界高14.08%。两种比例分母不同，不能混用。详见../../outputs/question2/benchmark/perfect_foresight/matched_ldr_summary.json；历史口径复核见../../outputs/question2/analysis/gap_audit。

## 9. β的定位与固定计划回放补充

β保留为基线/消融标记，不再作为LDR外另加的自由乘子。LDR中δ、λ已控制库存保留强度，再叠加β会带来重复参数化。β=0不是取消储能，而是R=Emin，有缺口时尽量放电。

当前主方案的配对控制器结论见论文§8.4：同计划、同日初库存下，LDR相对β=1与β=0的正式期配对节费分别为193,363.14元与64,236.94元。以下为历史口径（七天均值预测时期）的固定g回放记录，仅作对照：主方案换β=0少花105408.13元；情景价值方案换β=0反而多花71796.38元。二者末库存分别与原方案相同。说明原β=1保留规则不够经济，但价值判断合理的保留机制仍有作用。这是固定g控制器对照，不是重新生成后续g的独立策略成绩，详见../../outputs/question2/analysis/beta_audit/β保留机制分析.md。

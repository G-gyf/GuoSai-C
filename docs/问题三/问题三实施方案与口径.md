## 2. 关键口径（与 3.1.docx 的差异已在实现中落实）

1. **结算**：分段净结算（口径说明 §3.16）——`c·min(q0,qA) + 0.5c(q0−qA)⁺ + 1.5c(qA−q0)⁺`，等价 LP 目标为 `Σ[c·ã + 0.5c(p+q)]`。不采用"原计划全额收费再加下调罚金"（该口径使下调严格劣于不调整，机制失效）。
2. **负载预测**：周持久化 L_{d−7}，日内不更新（仅考察附件3 光伏信息，口径说明第 13 条）。
3. **光伏预报**：附件3 按整点瞬时口径，锚点 = 发布时间当刻已观测光伏 + 后续整点值，PCHIP 保形插值严格过锚（`src/data_pipeline/question3_forecasts.py`，锚点误差 < 1e-9 kW）；线性插值保留为对照，不覆盖旧数据。
4. **风险水平先验固定（报童推导，不按回测选参）**：
   - 0:00 计划 80%：每单位计划电成本 c、紧急电 5c → 覆盖率 5/(5+1)=0.8；
   - 调整阶段采用**双面分段报童曲线** `median(Q50, Q90, q0)`：下调方向边际只省 0.5c 违约费 → 最优覆盖 5/(5+0.5)≈90%；上调方向边际 2.5c（c+1.5c）→ 最优覆盖 2.5/5=50%；q0 为分段成本折点，两者之间最优即维持原计划。点预测仍作下限（与 0:00 曲线一致）。
   - 3.1.docx 的"调整沿用 80%"在上下调两个方向均无依据，已修正。
5. **阶段信号**：a_k 为阶段局部均值、对应当前生效预测版本——a6 vs N̂⁰（0—6 时）、a12 vs N̂⁶（6—12 时）、a18 vs N̂¹²（12—18 时；M6 用 N̂⁶）；情景评估与日内执行共用同一函数同式计算。
6. **校准评估时域**：每次校准只覆盖其承诺时域并加阶段末库存价值 ν·E（0:00 评 0—6 时、6:00 评 6—12 时、12:00 评 12—24 时），避免把下一阶段未锁定的参数卷入搜索。
7. **LDR 保底**：差分进化显式放入 β=1（零参数）与 β=0（R=Emin，δ=−9600、λ=0）两个候选，结果不劣于两者较优者才接受。
8. **冷启动与预热**：1/1 零计划 + R=Emin；1/2–1/7 负载用附件1 曲线；残差窗不足 21 日时全部校准回退零参数；2/1–12/31 为正式期（334 天、48096 区间）。
9. **模板口径**：result3 四表沿用问题二附录 B 映射（末列 0:00-0:10+1 为次日首区间；12/31 末列填 0）；"计划购电量"表存 q0 与面值费用 Σc·q0，"调整购电量"表存最终生效量 qA 与常规结算费（保留+下调+上调，不含紧急费），紧急购电另表。
